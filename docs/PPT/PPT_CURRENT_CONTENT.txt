Brief about the idea
TerraGrid  Disaster Intelligence, End to EndFull lifecycle: Predict  Prepare  Respond  Recover
The Problem
Natural disasters in APAC kill thousands yearly. The core issue isn't detectionsatellites handle that. The issue is speed and coordination. Disaster response today is siloed: meteorologists forecast, planners allocate resources days later, responders in the field lack real-time intel, and lessons learned never feed back to prevention. Decision-to-action takes hours. By then, preventable lives are lost.
The Solution
TerraGrid is an AI-powered disaster intelligence platform built around a four-phase lifecycle. Two phases are working in this prototype today; two are the near-term roadmap:
1. PREPARE AI-generated impact analysis and preparedness checklists, 7-day risk forecasting across 8 cities, per-audience agency alert drafting
2. RESPONSE  Live multi-hazard incident dashboard, AI decision support (Gemini), evacuation route pre-calculation, multi-channel WhatsApp/email alerting
3. PREDICT 6-month early warning from climate signals (ENSO, seasonal rainfall)
4. RECOVER  Before/after satellite damage assessment, recovery tracking
Unlike point solutions (fire detection, earthquake dashboards), TerraGrid connects phases into one workflow instead of leaving teams to stitch together disconnected tools. Every AI recommendation is logged  what data informed it, what the model returned  so the reasoning behind a suggested action is auditable, not a black box.

EXPECTED IMPACT
TerraGrid automates the data-gathering and recommendation pipeline, compressing hours of manual analysis into seconds to accelerate critical emergency responses.
THE CORE PROBLEM

TERRAGRID SOLUTION PATH
Multi-Source Intelligence
Auto-ingests 7 live APIs (NASA EONET, USGS, NOAA, GDACS, OpenWeather, OSM, OSRM) with zero manual data gathering.
AI Decision Support
Gemini 2.5 Flash generates action timelines, preparedness checklists, and agency alert drafts with confidence scoring.
Evacuation Route Pre-Calc
OSRM road-network routing with automatic geodesic fallback algorithms if primary routing services fail.
Multi-Channel Alerts
Delivers adapted messaging via WhatsApp (WAHA) and Email (Resend) tailored for farmers, hospitals, NGOs, and municipal corps.
Transparent Cross-Check Logging
Every external API payload and Gemini AI response is saved to disk as a timestamped JSON envelope  fully auditable, non-blackbox architecture.

USP of the proposed solution
USP #1: Phase Integration, Not a Point Solution
    PREPARE + RESPONSE connected today; PREDICT + RECOVER next on the roadmap  working toward full-lifecycle coverage, not stopping at detection.
USP #2: AI That Recommends, Not Just Displays
    Gemini drafts a response plan, checklist, and agency alert  confidence-scored, human-reviewed before send.
USP #3: Auditable AI, Not a Black Box
    Every API fetch and Gemini response is logged to disk, folder-wise  the reasoning behind any recommendation can be checked against raw data.
USP #4: Resilient Data Pipeline
    Automatic retry + backoff + graceful fallback when any source fails  the dashboard degrades, it doesn't break.
USP #5: Google Cloud Native Stack
    Vertex AI (Gemini) + Earth Engine (Sentinel-1 SAR); deployment target is Cloud Run, not yet deployed at submission time.

List of features offered by the solution
LIVE IN PROTOTYPE  RESPONSE phase (92% shipped)
  Live multi-hazard incident dashboard (earthquake, volcano, wildfire, storm, flood) with threat scoring
  AI Decision Support (Gemini 2.5 Flash): response plans, preparedness actions, agency alert drafts, deep dossiers
  Evacuation route pre-calculation (OSRM road-network routing, geodesic fallback on failure)
  Live infrastructure mapping  hospitals, fire stations, schools, power, bridges (OpenStreetMap/Overpass)
  Satellite cross-validation + Sentinel-1 SAR flood detection (Google Earth Engine)
  Multi-channel alerting  WhatsApp (WAHA) and email (Resend), per-audience templates
  Decision lineage / audit trail and real-time WebSocket dashboard updates
LIVE IN PROTOTYPE  PREPARE phase (89% shipped)
  7-day risk escalation forecast across 8 monitored cities (OpenWeatherMap)
  Risk Escalation Timeline  day-by-day confidence %, per city
  AI-generated Preparedness Checklist with per-agency task assignment
  Agency Alert Templates  tone adapted per audience (farmers, hospitals, NGOs, municipal corps)
  Source of Truth indicator  flags degraded/stale data instead of hiding it
PLATFORM-WIDE
  Raw data cross-check logging  every external API + Gemini response saved to disk, folder-wise, for audit
  Resilient data fetch  automatic retry + backoff and graceful fallback on source failure
ROADMAP  not yet built (shown honestly, not demoed)
  PREDICT phase (0/8 features)  ENSO monitoring, seasonal rainfall outlook, climate signal dashboard
  RECOVER phase (0/11 features)  before/after damage assessment, recovery milestone tracking

Technologies to be used in the solution
Languages:  Python 3.13, TypeScript / JavaScript
Backend:  FastAPI, Pydantic, SQLAlchemy + Alembic, APScheduler, websockets
Database:  PostgreSQL (psycopg2)
Frontend:  Vue 3, Vite, Pinia, Vue Router, vue-i18n, Mapbox GL JS, Axios, Tailwind CSS
Google Cloud / AI:  Vertex AI (Gemini 2.5 Flash), Google Earth Engine, Cloud Storage, Secret Manager
External data APIs:  NASA EONET, USGS Earthquake, NOAA, GDACS, OpenWeatherMap, OpenStreetMap / Overpass, OSRM
Alerting:  WAHA (WhatsApp), Resend (email)
DevOps:  Docker, Docker Compose, GitHub Actions CI, pytest
Note: Redis and Google Cloud Pub/Sub are present in the codebase but not actively wired into the running prototype at submission time  listed here for transparency, not counted as shipped features.
